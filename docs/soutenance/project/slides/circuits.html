On sépare strictement les circuits. Les 17 circuits d’entraînement et les 8 circuits de test sont tous réels, issus de la base de la TUM. Les circuits de test ne servent qu’à la mesure finale : le meilleur moment de chaque entraînement est choisi uniquement sur les circuits d’entraînement. Pendant l’entraînement, chaque épisode part d’un point au hasard pour que l’agent travaille tous les virages, pas seulement le premier.
