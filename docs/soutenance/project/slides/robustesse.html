Entraîné avec une adhérence variable, PPO est le meilleur agent sur piste humide. Les pilotes programmés connaissent l’adhérence ; les agents ne l’observent pas.

Source : results/eval_f1_v2.csv
Quand l’adhérence baisse, les agents perdent beaucoup. Sur piste humide, PPO entraîné avec une adhérence variable reste le meilleur, avec 9 tours sur 24. Sur piste glissante, aucun agent ne boucle un tour, alors que les deux pilotes programmés y arrivent presque toujours. Il faut le dire : les pilotes programmés connaissent l’adhérence et adaptent leur vitesse, les agents ne la perçoivent pas. On retrouve la conclusion de la série v1 : la variété à l’entraînement rend plus robuste.
